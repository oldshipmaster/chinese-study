# 字里少年宫

面向中国大陆小学一至六年级孩子的统编版语文动画学习网站。课程采用“东方自然乐园”视觉语言，通过 HTML、CSS 和 React 交互讲解拼音、识字、阅读、古诗、口语交际与习作。

在线学习：<https://oldshipmaster.github.io/chinese-study/>

## 当前课程规模

- 一至六年级上下册共 12 册、95 个单元、564 节可学习课程；
- 每课都有独立编辑的核心知识、例子、检查问题和答案，不使用占位课程；
- 拼音、识字、阅读、古诗、口语、习作、园地七类互动引擎；
- 每课采用八站自学课堂：情境导入、旧知热身、知识探秘、例子拆解、互动实验、创新挑战、五题闯关、错因拓展；
- 每课包含 5 张知识卡、3 个正式语文概念、3 个探究问题、4 件能力工具、正反例诊所、至少 2 项课型互动、3 条开放挑战路线、5 道分层题、跨学科连接和 30 秒复述卡；
- 一二、三四、五六年级分别采用启蒙、进阶、思辨难度，题目语言、表达量、支架和拓展深度不同；
- 47 个随站点发布的拼音 WAV，支持点击后标准速度或慢速播放，并显示口形与舌位提示；
- 自动保存每课学习位置、互动答案、表达草稿、错题、自检和掌握感；课程地图可继续未完成课堂；
- 支持单课重置、只重做错题、个性化复习处方和竹叶奖励；
- 适配电脑、平板与手机，支持键盘/辅助技术状态和减少动态效果。

课程依据课程标准与统编教材结构设计。讲解、例句、练习和动画脚本均为原创内容，不复制教材正文或插图。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

执行完整验证：

```bash
npm test
```

逐册审计 564 课的内容丰富度与数据完整性：

```bash
npm run audit:lessons
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```

## 主要内容位置

- 课程地图与课时装配：`app/data/curriculum.ts`
- 564 课独立内容种子：`app/data/lessonSeeds.ts`
- 七类互动与分年级丰富课堂：`app/data/richLesson.ts`
- 八站课堂界面：`app/components/LessonView.tsx`
- 断点续学：`app/lib/lessonDraft.ts`
- 拼音音频：`static-site/public/audio/`
- 全课程审计：`scripts/audit-rich-lessons.mjs`

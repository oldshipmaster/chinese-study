# 字里少年宫：小学语文动画课程设计规格

## 1. 产品目标

为中国大陆小学一至六年级学生制作一套可独立学习的语文课程网站。课程以现行统编版、人民教育出版社小学语文教材为对齐依据，覆盖一至六年级上下册共 12 册，并以 HTML、CSS 和 JavaScript 动画讲解知识点。

网站面向 6–12 岁儿童，不依赖家长或老师持续陪同。孩子应能自行选课、理解操作、完成练习、获得反馈并继续下一课。

## 2. 内容范围与边界

- 建立 12 册完整课程地图，按教材的单元与栏目组织，包括课文、识字、汉语拼音、语文园地、口语交际、习作、快乐读书吧和综合性学习等类型。
- 采用分层混合建设方式：所有课次进入完整课程地图；拼音、识字写字、古诗、阅读、口语交际和习作使用专属动画课堂模板；重点课文增加独立场景动画。
- 第一版必须提供可真正完成学习流程的代表性动画课程，同时为其余课次提供明确的课程名称、所属单元、学习目标、课程类型和建设状态。
- 教学讲解、例句、练习和动画脚本均为原创内容。网站依据课名、语文要素与课程标准设计教学，不复制受版权保护的教材全文、插图或配套资源。
- 教材目录应使用当前可核对的官方或权威来源。目录存在版本差异时，在课程数据中标注适用版本，并允许后续调整，不把目录硬编码进视图组件。

## 3. 体验方向

采用“东方自然乐园”视觉方向，品牌名为“字里少年宫”。

- 主色为宣纸米白、玉青、竹绿、杏黄和天青。
- 视觉元素使用水墨淡彩、远山、池塘、竹子和扁平动画角色，以 CSS 图形、排版和动效实现，不依赖装饰性外部图片。
- 界面保持柔和、清晰和现代，不做幼儿园式堆叠装饰。
- 当前任务用杏黄强调，完成状态用玉青或竹绿表达，正文使用高对比墨色。
- 低年级使用大字号、大点击区、短指令和明显的下一步；高年级可以提高信息密度，但维持相同的操作模型。

## 4. 信息架构

### 4.1 首页

首页第一屏直接呈现学习状态与继续学习入口，而不是通用宣传页。主要区域包括：

- 品牌与当前学习状态；
- 一至六年级及上下册入口；
- “继续学习”动画课堂卡片；
- 今日学习路径；
- 总体进度、竹叶奖励和连续学习天数；
- 课程能力地图，展示拼音、识字、阅读、古诗、表达等成长方向。

### 4.2 课程地图

用户选择年级和册次后，按单元查看完整课程列表。每个课次显示课程类型、预计时长、完成状态和学习目标。已完成、正在学习、可开始与建设中使用文字和图形共同区分，不能只依赖颜色。

### 4.3 动画课堂

每节完整课程遵循同一条学习路径：

1. 动画导入；
2. 知识讲解；
3. 跟读、观察或动手练习；
4. 三题闯关；
5. 学习总结与奖励。

课堂提供播放、暂停、重播、上一步和下一步。动画不得强制快速推进；重要讲解需要儿童主动确认后进入下一步。

## 5. 动画课程模板

### 5.1 拼音课堂

用口型提示、发音位置、字母形状联想、声调轨迹与拼读组合动画讲解。代表性完整课程为“一年级上册：a o e”。

### 5.2 识字写字课堂

用象形联想、部件拆分、笔顺逐画、字义场景和组词练习讲解。动画笔画按顺序出现，并提供暂停和重播。

### 5.3 古诗课堂

先呈现意境场景，再逐句解释关键词、节奏和情感，最后完成补句、排序或情境选择练习。不得直接以完整教材页面作为课程内容。

### 5.4 阅读课堂

用角色、事件、时间线、段落关系和关键词高亮帮助孩子理解文章。高年级逐步加入概括、推断、表达方法和观点证据。

### 5.5 口语交际与习作课堂

使用生活情境、表达支架、句子积木和逐步成稿流程。课程提供示例结构，但不替孩子生成唯一标准答案。

## 6. 交互与状态

- 孩子无需注册即可学习。
- 当前册次、最近课程、课次完成状态、竹叶奖励和连续学习信息保存在当前设备。
- 状态数据采用版本化结构，课程数据更新后仍能读取已有进度。
- 首次访问没有进度时，从一年级上册代表性课程开始；已有进度时优先显示继续学习。
- 建设中课程必须显示学习目标与状态说明，不出现空白页面或无响应按钮。

## 7. 技术结构

- 使用 Sites 初始化的现有 vinext 项目结构。
- 课程目录与课程元数据放在独立数据模块；页面和动画组件只消费统一的课程接口。
- 动画课堂按课程类型拆分为可复用组件，专属场景作为模板的可选扩展，不在单一页面中堆叠全部逻辑。
- 动画优先使用 CSS transform、opacity、clip-path 与少量受控 JavaScript 状态，避免大体积视频和高耗能持续动画。
- 第一版不引入账号、云端同步、支付、社交或教师后台。

## 8. 响应式与无障碍

- 支持桌面、平板和手机；触屏与键盘均能完成主要操作。
- 所有交互使用语义化按钮和清楚的可见标签，保留明显焦点状态。
- 文字、状态和按钮满足清晰对比；状态不只依赖颜色。
- 遵循 `prefers-reduced-motion`，在减少动态效果模式下关闭循环和大幅位移动画，但保留教学步骤与内容变化。
- 低年级主要操作点击目标不小于适合触控的尺寸，避免密集小图标。

## 9. 错误与降级

- 本地学习进度不可用时，课程仍可正常浏览和学习，只是不保存进度，并显示简短提示。
- 找不到课程数据时返回课程地图和明确说明，不显示技术错误。
- 动画脚本不可用时显示同等顺序的静态讲解步骤。
- 课程建设中状态必须可辨认，并提供返回课程地图或选择同类课程的操作。

## 10. 第一版交付标准

- 可浏览一至六年级上下册共 12 册的课程地图与代表性课程数据。
- 首页、课程地图和动画课堂形成完整可操作路径。
- “a o e”课程完整实现五阶段独立学习流程、播放控制与三题闯关。
- 至少展示识字、古诗、阅读、口语交际和习作模板的真实课程卡片与学习目标。
- 进度、奖励和最近课程能在当前设备刷新后恢复。
- 电脑、平板和手机布局可用，并支持减少动态效果。
- 正式构建成功后通过 Sites 私密发布。

## 11. 后续扩充顺序

第一版发布后，按“一册一批”的节奏补全深度课程。优先顺序为一年级上册、一年级下册，再依次扩展至六年级；每批先补齐高频基础技能和单元重点课，再完善其余课次的专属动画。

# 字里少年宫逐课精编设计

## 目标

把目前依赖课程类型生成的通用课堂，逐册升级为与课题对应的原创自学课堂。每一课必须出现本课独有的观察对象、知识方法、示例和检测题，不能只替换课程标题。

## 推进顺序

按一年级上册、下册到六年级下册逐册交付。每完成一册，就运行内容质量测试、构建测试并部署；尚未精编的课程继续使用现有课堂，保证网站始终可学习。

## 内容模型

为课程增加 `LessonSeed` 编辑层。每个种子保存本课独有的核心知识、观察例子和理解检测。`buildLesson` 将种子与课程类型的交互方法组合成五段课堂，但种子内容必须直接决定知识锦囊、例子演练、练习和闯关题。

## 第一里程碑

- 覆盖一年级上下册的全部课程，而不只覆盖代表课。
- 拼音课讲口形、发音部位或拼读规则；识字课讲字形、字义或构字；阅读课讲人物、顺序或画面；古诗课讲意象和画面；口语课讲具体表达步骤；园地课讲对应积累方法。
- 页面显示“逐课精编”标识，让家长能分辨内容质量。
- 测试校验一年级每个课程 id 都有独立种子，且不存在通用的占位式例句。

## 验证

- 内容测试：一年级课程种子全覆盖、知识文本互不重复、每条种子字段完整。
- 交互测试：课堂使用种子生成的知识、示例和闯关题，并显示精编标识。
- 工程测试：`npm run lint`、`npm test` 全部通过。

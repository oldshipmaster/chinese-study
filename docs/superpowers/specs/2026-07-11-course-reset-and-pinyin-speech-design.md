# 单课重置与拼音语音播放设计

## 目标

为“字里少年宫”增加单个课程进度重置功能，并为 `a o e` 拼音动画课增加设备中文语音播放，让孩子可以重新学习并听到发音。

## 单课重置

- 仅已完成课程显示“重置进度”。
- 入口同时出现在课程地图的已完成课程卡片和课堂顶部。
- 点击重置后显示二次确认，明确说明将删除本课完成记录并扣回 3 片竹叶。
- 确认后从 `completedCourseIds` 中移除课程 id，竹叶减少 3 且最低为 0，并立即写入 `zili-progress-v1`。
- 若课程未完成，重置操作返回原进度，不扣竹叶；重复触发同一课程重置也不重复扣叶。
- 课堂内重置后保留在当前课程，但动画阶段、当前字母、答题选择和反馈文案全部恢复初始状态。
- 课程卡片重置后恢复“开始学习”状态。

进度逻辑由纯函数 `resetCourse(progress, courseId)` 实现，不直接访问浏览器存储。界面继续通过 `CourseApp.persist()` 统一保存。

## 拼音语音播放

- `a o e` 课堂使用浏览器 Web Speech API 的 `window.speechSynthesis` 与 `SpeechSynthesisUtterance`。
- 朗读语言设置为 `zh-CN`，朗读文本使用适合中文语音引擎的发音提示，而不是直接依赖英文字母名称。
- 点击任一字母时，先切换当前字母，再播放该字母发音。
- 增加带可见文字的“听发音”按钮；按钮在语音播放时显示正在播放状态。
- 动画处于播放状态且当前字母自动切换时，依次朗读新的当前字母。
- 用户点击暂停、重播、返回课程地图、切换课程或重置进度时，调用 `speechSynthesis.cancel()` 停止当前语音。
- 浏览器不支持 Web Speech API 时，按钮保持可见但不可播放，并显示“当前设备不支持语音朗读”的明确提示；课程动画和练习继续可用。
- 语音必须由用户首次点击触发，遵守移动端浏览器的自动播放限制。

## 组件接口

- `app/lib/progress.ts` 导出 `resetCourse(progress, courseId)`。
- `CurriculumView` 新增 `onResetCourse(courseId)` 回调，并只在 `done` 为真时显示重置按钮。
- `AoeLesson` 新增 `onReset()` 回调；内部使用统一的 `resetLessonState()` 重置课堂状态。
- `CourseApp` 负责确认提示、调用 `resetCourse`、持久化结果和触发课堂重置。
- 语音播放逻辑封装在 `AoeLesson` 内部，不进入全局进度模型。

## 无障碍与交互

- 重置按钮与学习主按钮视觉层级分开，避免误触。
- 确认文案包含课程名称、扣回竹叶数量和不可撤销说明。
- 语音按钮有可见标签与 `aria-pressed` 状态；语音状态通过 `aria-live` 文案反馈。
- 重置与语音控件均满足键盘操作和最小触控尺寸。

## 验收

- 完成课程重置后，完成 id 被移除且竹叶减少 3。
- 重复重置、重置未完成课程都不改变进度；竹叶不会低于 0。
- 课程地图和课堂顶部均存在正确条件下显示的重置入口。
- `a o e` 三个字母和“听发音”按钮可触发中文语音；暂停、返回和重置会停止语音。
- 不支持语音的设备显示降级提示。
- `npm test` 全部通过，GitHub Pages 静态构建成功并自动部署。

# 字里少年宫：全量小学语文课程完成规格

## 目标

把现有代表性课程版本升级为一至六年级上下册全量可自学版本。所有课程卡片都必须能进入完整课堂，不再出现“课程正在生长”的占位页。

## 范围

- 覆盖统编版小学语文 12 册教材目录中的课文、识字、汉语拼音、语文园地、口语交际、习作、快乐读书吧、综合性学习和古诗词诵读。
- 课程名称与结构参考 TapXWorld/ChinaTextbook 中的公开小学语文统编版 PDF 目录。
- 网站只保存原创讲解、例句、练习和动画脚本，不复制教材正文、插图或整页排版。
- `a o e` 继续保留专属发音课堂和点击播放语音行为。
- 其他课程进入统一自学课堂：动画导入、知识锦囊、例子演练、动手练习、三题闯关。

## 数据结构

每个 `Course` 都包含 `lesson: LessonContent`。`LessonContent` 包括导入文案、知识点、动画帧、例子、练习和三题 quiz。课程状态只保留 `ready`，课程地图不再显示建设中状态。

## 通用课堂

通用课堂根据课程类型切换符号、讲解语气和练习方式。孩子答完三题并全部正确后，按钮从“下一步”变成“完成课程”，点击后回到课程地图；完成状态继续写入本地进度并奖励 3 片竹叶。

## 验证

- 静态测试检查 12 册、至少 220 节课程、无 `building` 占位、每课都有自学学习包。
- 组件测试检查通用课堂不含占位文案，且有完成课程逻辑。
- 完整执行 `npm test`，包含 vinext 构建和 GitHub Pages 构建。

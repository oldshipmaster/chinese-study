# 单个课程重置进度设计

## 目标

允许孩子重置某一门已完成课程的学习进度，从头重新学习，同时扣回该课程完成时获得的 3 片竹叶，不影响其他课程与连续学习天数。

## 入口

- 课程地图中，已完成课程卡片同时显示“再学一次”和“重置进度”。
- 已完成课程的课堂顶部显示“重置进度”。
- 未完成课程不显示重置入口。

## 交互

1. 点击“重置进度”后显示确认提示，明确写出课程名、完成记录将被移除，并扣回 3 片竹叶。
2. 取消确认时不修改任何状态。
3. 确认后立即更新界面并写入 localStorage。
4. 从课程地图重置后，该课程卡片恢复为“开始学习”。
5. 从课堂顶部重置后，继续停留在本课，但课堂步骤、播放状态、答题选择和提示全部恢复到初始状态。

## 数据规则

在 `app/lib/progress.ts` 增加纯函数：

```ts
resetCourse(progress: LearningProgressV1, courseId: string): LearningProgressV1
```

- 课程已完成时，从 `completedCourseIds` 中移除课程 ID，并扣减 3 片竹叶。
- 竹叶最低为 0，不允许负数。
- 课程未完成时原样返回，不扣叶。
- 重复重置同一课程不会重复扣叶。
- `streak` 与其他课程完成状态保持不变。
- `recentCourseId` 保持当前值，方便孩子继续找到刚刚重置的课程。

## 组件边界

- `CourseApp` 统一执行确认、调用 `resetCourse`、持久化状态并生成课堂重置序号。
- `CurriculumView` 只负责展示已完成课程的重置按钮，并通过 `onResetCourse(courseId)` 上报意图。
- `AoeLesson` 接收 `onReset`，在课堂顶部展示入口；`CourseApp` 通过改变组件 `key` 让课堂内部状态完整重新初始化。
- 其他未完成的模板课程不展示重置入口。

## 可访问性

- “再学一次”和“重置进度”使用独立的原生按钮。
- 重置按钮使用清楚文字，不只依赖图标或颜色。
- 确认提示说明不可含糊，取消是无副作用的安全路径。

## 验收

- 进度测试覆盖完成课程重置、未完成课程重置、重复重置、竹叶下限和其他状态不变。
- 渲染与源码测试覆盖课程卡片和课堂顶部两个入口。
- `npm test` 全部通过。
- GitHub Pages 构建通过并自动部署到 `https://oldshipmaster.github.io/chinese-study/`。
